URL 리스트만 넣으면 고해상도 캡처부터 파워포인트(PPTX)·엑셀(XLSX) 완성본까지 100% 전자동 생성

1. 이게 구체적으로 무엇인가요? (What is SnapDeck?)
1-1. 배경: 전 세계 지식 근로자들이 겪는 '스크린샷 지옥'
실제 레딧(Reddit), 블라인드(Blind) 등에서 가장 흔하게 터져 나오는 한탄 중 하나입니다.

"경쟁사 150곳 랜딩페이지 비교 보고서 만들라고 해서 하루 종일 캡처만 하다가 멘탈 나갔습니다."
"사이트 개편 후 200개 페이지 모바일/데스크톱 검수 캡처 떠서 PPT 200장 만드느라 주말이 삭제됐어요."

사람이 웹페이지를 하나하나 캡처해서 보고서를 만들 때 거치는 비효율적인 과정:

브라우저 새 탭 열기
URL 붙여넣고 로딩 대기 (10초)
화면을 가리는 쿠키 배너, 광고 팝업 수동 닫기 (5초)
캡처 도구(캡처 도구, 단축키)로 영역 드래그 or 풀페이지 캡처 확장 프로그램 클릭 (10초)
PPT/엑셀 창으로 전환 (3초)
붙여넣기(Ctrl+V) 후 이미지 크기 리사이징 및 가운데 정렬 (15초)
상단에 웹사이트 제목 및 접속 URL 텍스트 박스 만들어서 입력 (15초) 👉 1개 URL당 최소 1분 ~ 1분 30초 소요 ➔ 300개 작업 시 약 7.5시간(하루 근무시간 전체 증발!)
1-2. 제품 정의
SnapDeck은 엑셀이나 텍스트 파일로 된 URL 목록을 드래그앤드롭하기만 하면, 내장된 고성능 헤드리스 브라우저 엔진이 백그라운드에서:

자동으로 각 웹페이지에 접속하여 광고/쿠키 팝업을 깨끗이 제거하고,
지정한 디바이스 뷰포트(데스크톱 FHD/4K, 태블릿, 모바일)에 맞춰 완벽한 고해상도 스크린샷을 촬영한 뒤,
사이트 메타데이터(타이틀, 파비콘, 캡처 일시, HTTP 상태)와 함께 전문가용 파워포인트(PPTX) 슬라이드 및 엑셀(XLSX) 시트로 100% 자동 레이아웃 배치해 주는 원스톱 문서화 데스크톱 소프트웨어입니다.
2. 어떻게 사용하는 건가요? (How It Works: 3-Step)
복잡한 설정이나 코딩 지식은 전혀 필요 없습니다. 마우스 클릭 3번이면 보고서가 완성됩니다.

Mermaid diagram
[Step 1] URL 목록 입력 (초간단 인풋)
드래그 앤 드롭: 엑셀(.xlsx), .csv, 또는 텍스트(.txt) 파일을 앱 화면 위에 얹기만 하면 끝.
클립보드 즉시 붙여넣기: 웹 브라우저나 메신저에서 URL 뭉치를 복사해 Ctrl+V로 붙여넣기 지원.
URL 유효성 자동 검사: 중복된 URL, 오타난 프로토콜(htp:// 등)을 사전에 자동 필터링.
[Step 2] 원클릭 캡처 & 템플릿 옵션 선택
캡처 모드 선택:
🖥️ 뷰포트 캡처(Above the Fold): 사용자가 접속하자마자 보는 첫 화면만 깔끔하게 캡처.
📜 풀페이지 캡처(Full Page): 아래로 스크롤되는 페이지 전체를 끊김 없이 한 장의 롱 이미지로 캡처.
🎯 특정 셀렉터 캡처: 특정 배너, 상품 영역, 로그인 폼 등 원하는 요소만 핀포인트 캡처.
디바이스 프리셋:
데스크톱(1920×1080), 맥북 레티나, 아이폰 15 Pro, 갤럭시 S24, 아이패드 등 클릭 한 번으로 전환.
문서 템플릿 선택:
PPTX 타입 A (1 Slide 1 Page - 상세 분석형): 좌측에 고해상도 스크린샷, 우측에 [사이트명 / URL / 메모 / 날짜] 배치.
PPTX 타입 B (1 Slide 2~4 Pages - 비교형): 경쟁사 A/B/C를 한 슬라이드에서 나란히 조망.
XLSX 타입 (스프레드시트 셀 삽입형): 행(Row)마다 사이트명, 링크, 썸네일 이미지가 셀 안에 정갈하게 임베드.
[Step 3] [문서 생성 시작] 클릭 ➔ 결과 확인
프로그레스 바(진행률)와 실시간 캡처 썸네일 미리보기가 제공됩니다.
작업이 완료되면 알림음과 함께 파워포인트나 엑셀 파일이 자동으로 열립니다.
3. 뭘 할 수 있는 건가요? (Core Capabilities & Killer Features)
경쟁 오픈소스 스크립트나 허술한 캡처 도구와 차별화되는 상용 수준의 5대 킬러 기능입니다.

🔥 Feature 1. "클린 캡처" (팝업 & 쿠키 동의 배너 100% 자동 소멸)
글로벌 웹사이트 접속 시 화면의 절반을 가리는 "Accept Cookies", "GDPR 배너", 뉴스레터 구독 유도 모달, 채널톡/인터콤 챗봇 아이콘을 감지하여 캡처 직전 자동으로 DOM 트리에서 삭제하거나 닫습니다.
사용자가 보고서에 수동으로 가위질이나 모자이크를 할 필요 없이, 언제나 잡티 없는 순수 웹 UI만 캡처됩니다.
🔥 Feature 2. 로그인 세션 유지 (인트라넷 & 유료 대시보드 캡처)
많은 실무자들의 진짜 고통은 "로그인해야 들어갈 수 있는 사내 어드민, 결제 대시보드, 유료 솔루션 화면"을 캡처하는 것입니다.
SnapDeck은 '1회 브라우저 로그인 연동(Session Vault)' 기능을 제공합니다. 사용자가 앱 내장 창에서 1번 로그인해 두면 세션 쿠키를 로컬에 암호화 보관하여, 비공개 인트라넷 300개 페이지도 문제없이 일괄 캡처합니다.
🔥 Feature 3. 레이아웃 붕괴 방지 지능형 대기 (Smart Hydration Wait)
최신 SPA(React, Vue, Next.js) 사이트는 접속 후 데이터가 늦게 로딩되어 빈 화면이나 로딩 스피너만 캡처되는 참사가 빈번합니다.
SnapDeck의 스마트 엔진은 네트워크 유휴 상태(NetworkIdle) + 스켈레톤 UI 소멸 감지 + 레이지 로딩(Lazy-loading) 이미지 자동 스크롤 트리거를 실행한 후 완벽한 타이밍에 셔터를 누릅니다.
🔥 Feature 4. 마이크로소프트 오피스 완벽 호환 (Native Vector PPTX/XLSX)
이미지를 대충 찌그러뜨려서 얹는 것이 아니라, 16:9 와이드스크린 규격에 맞춰 비율 손실 없이 자동 중앙 정렬됩니다.
PPT 슬라이드 상단의 제목 텍스트 박스에는 해당 웹페이지의 <title> 태그 내용이 자동 기입되며, URL 텍스트에는 클릭 시 브라우저로 이동하는 하이퍼링크가 자동으로 심어집니다.
엑셀 출력 시 최신 Excel의 셀 이미지 삽입(DISPIMG 호환)을 지원하여 셀 크기를 조절해도 이미지가 깨지지 않습니다.
🔥 Feature 5. 로컬 구동으로 보안 걱정 0% (Privacy-First)
기업 고객(컨설팅, 대기업, 금융권)은 외부 SaaS 웹사이트에 사내 URL이나 경쟁사 리서치 내역을 올리는 것을 극도로 꺼립니다.
SnapDeck은 100% 사용자의 PC 로컬 머신에서 브라우저를 띄워 캡처하고 파일을 생성하므로 외부 서버로 데이터가 단 1바이트도 전송되지 않습니다.
